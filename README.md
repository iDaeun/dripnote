# 드립노트

핸드드립 레시피를 보며 내리고, 원두·감상·사진을 기록하는 개인용 웹앱(PWA).
서버 없이 아이폰 안(IndexedDB)에만 데이터를 저장한다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 껍데기와 하단 탭 |
| `app.js` | 화면과 기능 전부 |
| `db.js` | 폰 안 저장소(IndexedDB) |
| `style.css` | 디자인 (라이트/다크 모드) |
| `sw.js` | 오프라인에서도 열리게 하는 캐시 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 이름과 아이콘 |

## 내 맥에서 띄워보기

```bash
python3 -m http.server 8123
```

브라우저에서 http://localhost:8123 을 연다.

## 아이폰에 올리기 (GitHub Pages, 무료)

1. GitHub에서 새 저장소를 만든다 (예: `dripnote`).
2. 이 폴더의 파일을 전부 올린다 (`.claude` 폴더는 빼도 된다).
3. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 두고 저장한다.
4. 1~2분 뒤 나오는 주소(`https://<아이디>.github.io/dripnote/`)를 아이폰 사파리로 연다.
5. 공유 버튼 → **홈 화면에 추가**.

반드시 홈 화면 아이콘으로 열어서 쓴다. 사파리 탭에서 쓰면 오래 안 열었을 때 데이터가 지워질 수 있다.

## 주의

- 데이터는 이 폰에만 있다. 홈 화면 아이콘을 지우거나 사파리 웹사이트 데이터를 지우면 사라진다.
- 주소(도메인)를 바꾸면 빈 앱으로 시작한다.
- 백업(내보내기/가져오기)은 아직 없다. 기획서의 할 일에 있다.

## 1차에서 빠진 것

- 유명 레시피 프리셋, 기록 비교 (기획서 3차)
- 블로그 링크 미리보기: 서버가 없어서 제목은 직접 입력한다. 유튜브는 썸네일이 자동으로 나온다.
- 백업 기능
